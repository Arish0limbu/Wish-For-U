# Wish-For-U
# https://arish0limbu.github.io/Wish-For-U/

A romantic/dedication website for someone special.

## Features

- **Home Page** - Main landing page with navigation
- **Wishes** - Collection of wishes for your loved one
- **Memories** - Photo gallery of special moments
- **Love Letter** - A heartfelt love letter
- **Our Story** - Timeline of your journey together
- **Surprise** - A special surprise feature

## Structure

```
Wish-For-U/
├── index.html          # Main landing page
├── wish.html           # Wishes page
├── memory.html         # Memories page
├── love-letter.html    # Love letter page
├── our-story.html      # Our story page
├── surprise.html       # Surprise page
├── css/                # Stylesheets
├── js/                 # JavaScript files
├── images/             # Image files
├── music/              # Music files
└── assets/             # Icons and fonts
```

## Usage

1. Open `index.html` in a web browser
2. Navigate through the different pages
3. Customize the content to make it personal

## Customization

- Replace placeholder images in the `images/` folder
- Add your own music files in the `music/` folder
- Edit HTML files to add your personal content
- Customize CSS files to change the design
- Modify JavaScript files to add interactivity

## Music Player

The project includes a music player class in `js/music-player.js`. You can integrate it into any page to play background music.
